### 3.2.2 变量

- 变量是指在程序运行中，其值可以被改变的量
- 变量代表计算机内存中的某一存储空间，该存储空间中存放的数据就是变量的值
- 在同一程序块中，每个变量都有唯一的名字，不能被重复定义
- 使用变量时必须“先定义，后使用”

变量命名的规定：C 语言规定**标识符**只能由字母、数字和下划线三种字符组成，且第一个字符必须为字母或下划线。

可以的：
```
sum, _total, month, Student_name, lotus_1_2_3, BASIC, li_ling
```
不可以的：
```
M.D.John, ￥123, 3D64, a>b
```

### 声明和使用变量

- 声明变量：
  `数据类型 变量名;`
```c
int a;
```

- 定义时初始化变量：
  `数据类型 变量名 = 值;`
```c
int a = 1;
```

- 定义后初始化变量（批注：记忆里并不推荐这种做法，可读性低且冗余）
  `变量名 = 值;`
```c
int a;
a = 1;
```

给变量赋值，除了给一个直接的值以外，还可以通过计算获得。

### 书写变量说明

- 可说明多个相同类型的变量，各变量名之间用逗号间隔，类型说明符与变量名之间要有空格
```c
int a, b, c;
float sum, price;
```
- 变量的声明一般放在函数的最前面（实际用起来一般是放在函数中某一段功能的前面）

### 3.2.1 整型

字节：8个二进制位，是最小的存储单位


| 名称    | 全称类型说明符   | 缩写类型说明符 | 位数 | 范围                       |
| ----- | --------- | ------- | -- | ------------------------ |
| 整型 | int       | int     | 16 | -32768 至 +32767          |
| 短整型   | short int | short   | 16 | -32768 至 +32767          |
| 长整型   | long int  | long    | 32 | -2147483648 至 2147483647 |



纠正如下（两个都是 Windows，所以 `long` 在两边都是 32 位——Windows 用的是 LLP64 模型，只有 `long long` 和指针随位数变）：

| 名称 | 全称类型说明符 | 缩写类型说明符 | 位数 | 范围 |
|------|--------------|--------------|------|------|
| 短整型 | short int | short | 16 | -32768 至 +32767 |
| 整型 | int | int | 32 | -2147483648 至 +2147483647 |
| 长整型 | long int | long | 32 | -2147483648 至 +2147483647 |
| 长长整型 | long long int | long long | 64 | -9223372036854775808 至 +9223372036854775807 |

位数差异不在类型本身，而在**指针和无符号尺寸类型**上：

| 类型 | 机房 32 位 | 笔电 64 位 |
|------|-----------|-----------|
| `short` / `int` / `long` | 16 / 32 / 32 | 16 / 32 / 32（一样） |
| `long long` | 64 | 64（一样） |
| 指针（如 `int*`） | 4 字节 | 8 字节 |
| `size_t` | 4 字节 | 8 字节 |

你原来那张表其实是 16 位 DOS 时代（Turbo C）的情况：`int` 16 位、`long` 32 位。笔记里可以注明一句"32/64 位 Windows 上 `int` 均为 32 位，指针才是区分平台的地方"。另外写 64 位整数常量记得加后缀 `LL`，比如 `9223372036854775807LL`。

### 整型常量

整型常量即整常数。在 C 语言中，整常数可以用以下三种形式表示：

1. 十进制整数
    如：123, -456
2. 八进制整数，以 0 开头的是八进制数
    如：0123 是 八进制 123，等于十进制的 83，-011 表示八进制数 -11，等于十进制的 -9
3. 十六进制整数，以 0x 开头的数是 16 进制数
    如：0x123 代表 十六进制数 123，等于十进制的 291，-0x12 等于十进制 -18

### 3.2.3 字符型变量

- 字符变量用来存放*一个*字符常量，字符型用 char 表示。一般以一个字节来存放一个字符
- 字符数据在每次内存中的存储形式
  - 并不是把该字符本身放到内存中，而是将该字符对应的 ASCII 码存放到内存中
  - 因此字符型和整型可以相互运算
