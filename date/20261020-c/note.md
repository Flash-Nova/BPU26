    `"How do you do."`, `"CHINA"`, `"a"`, `"$123.45"`


### 各类数值型数据间的混合运算

混合运算：整型（包括 int，short，long）、浮点型（包括 float，double）可以混合运算。在进行运算时，不同类型的数据要先转换成同一类型，然后进行运算。

说明：这种类型转换是由系统自动进行的。
\* 精度由低到高进行转换
```
char, short
-> int
-> unsigned
-> long
-> double <- float
```

### 赋值语句中的类型转换

- 自动类型转换：上面简单讲了

- 强制类型转换
    - 语法：`(类型名)变量或数值`
    - 例如：
    ```c
    float x = 5.4;
    b = (int)x;
    ```
    ```c
    则：b = 5;
    ```

- 补充: **C 语言里没有 `int(x)` 这种语法。**
`int(x)` 是 **C++ 才支持的“函数式强制类型转换”（Function-style cast）**，而且它也不是 C++11 才有的，C++98 就已经支持了（C++11 引入的是更安全的 `static_cast<int>(x)`）。


# 2 运算符和表达式

## 算术运算符 2-1

- 一元（单目运算符）：一个操作数，譬如 `++ --`
- 二元（双目运算符）：两个操作数，譬如 `+ - * / %`

### 算数运算符说明

- 除法运算：参与运算的操作数均为整型时，结果也为整型，舍去小数。如果有一个实型，结果为双精度实型。
    如：
    ```c
    7 / 4 -> 1
    7.0 / 4 -> 1.75
    (double) 7 / 4 -> 1.75
    ```

- 求余运算（取模）：参与运算的**操作数必须为整型**，结果也为整型，结果符号与被除数相同。

## 算术运算符 2-2

自增、自减
```c
num2 = ++num1;
// 前缀、前置，等价于
num1 = num1 + 1;
num2 = num1;

num2 = num1++;
// 后缀、后置，等价于
num2 = num1;
num1 = num1 + 1;

--num1 /*和*/ num1-- //同理
```

案例分析
```c
int a = 1, b = 10, c;
c = a + (++b);
```
结果：
```
c = 12
b = 11
```
