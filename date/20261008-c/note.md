## 输出函数 printf()

`printf("格式字符串", 参数表);`
`printf("a = %d, b = %d, a, b);`

## 输出整数的格式字符：%d

- `%d`：输出整数
- `%md`：指定输出的最小宽度，占 `m` 列，右对齐，左补空格，若实际长度大于 `m`，则原样输出
- `%-md`：输出宽度按左对齐，右补空格
  这里 `-` 指的是负值
- `\n`：换行符
- `\t`：制表符
- `\b`：退格 
- `\r`：回车
- `\f`：换页
- `\\`：转义
- `\ddd`：八进制
- `\xdd`：十六进制

代码 1
```c
void main() {
    int a = 123;
    printf("%-5d\n", a);
    printf("%5d\n", a);
}
```

样例输出
```plaintext
123  
  123

```

## 输出小数的格式字符：%f


- `%f`：以小数形式输出实数。系统自动指定宽度，整数部分会全部输出，并输出六位小数
- `%m.nf`：输出共占 `m` 列，其中小数部分占 `n` 列，小数点占一列。若实际长度 `<m`，左补空格，右对齐，否则，安实际数值原样输出
- `%-m.nf`：依旧左对齐，右补空格

代码 2
```c
#include <stdio.h>
void main() {
    float a, b;
    a = 3.14;
    b = 0.618;
    
    printf("a 的值：%5.1f\n", a);
    printf("b 的值：%-5.1f\n\n", b);

    printf("a 的值：%f\n", a);
    printf("b 的值：%.2f\n", b);
}
```

样例输出
```plaintext
a 的值：  3.1
b 的值：0.6  

a 的值：3.140000
b 的值：0.62

```

## 输出字符的格式符：%c

- `%c`：用于输出一个字符
- `%mc`：输出占 `m` 列，左补空格

代码 3
```c
#include <stdio.h>
void main() {
    char ch;
    ch = 'A';
    printf("%c\n", ch);
    printf("%3c\n", ch);
}
```

样例输出
```plaintext
A
  A

```
