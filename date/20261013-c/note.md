## scanf 函数

`scanf` 函数从标准输入（键盘）**读取**信息，按照格式描述把输入的信息转换为指定数据类型的数据，并把这些数据赋给指定的程序变量。
```c
scanf("%d", &num);
```
- `%d` 格式符
- `&` 传变量的地址
- `num` 变量名

* `%d`、`%f`、`%s` 之间：加不加空格都行
`%c` 之前：想跳过空白必须加一个空格
别在格式串末尾乱加 `\n`（会等你多输入一次）

如 
```c
scanf("a = %d, b = %d", &a, &b);
```
用户必须输入形如
```plaintext
a = 3, b = 4
```
才能读进去，否则是读不进去的

- C 语言一般通过先 `printf` 输出提示，再 `scanf` 抓输入，并不像 python 那样一个 `input()` 既有提示又能抓输入

## 常见错误

- 拼写错误
- `#include` 少 `<>`，行末不要分号
    - 可以用 `""`，但一般只用于本地头源
- `main` 函数缺少 `()`，大小写严谨，不能 `Main`
- 语句结束少分号
- 输出语句中的格式符使用混乱
- 输出分行采用多个 `printf` 可读性高
- 输入时忘记 `&` 传址
- 变量忘记声明
